# 青年的工具（ymkit）

《饥荒联机版》合集工具模组，当前版本 `2.4.27`。模组提供黑曜石战斧、魔法剪刀和力量魔杖，并兼容 ActionQueue RB3 的批量操作。

## 功能

### 黑曜石战斧

- 54 点基础攻击、5 点位面伤害，手持移动速度提升 25%。
- 支持范围收割、铲掘、3 倍效率采矿、3 倍效率砍树和捕虫。
- 可配置隔空执行铲掘、采矿和砍树。
- 采集与捕虫使用快速动作，并支持 ActionQueue RB3 左键框选。

### 魔法剪刀

- 真实伤害可在模组配置中设为 `54` 至 `9999`，玩家目标不会被无视无敌状态。
- 可拆解有配方且允许反建造的物品，并返还材料。
- 可切换为 10 倍效率锤子形态，支持隔空操作和 ActionQueue RB3。

### 力量魔杖

- 使用懒人魔杖的传送机制，无耐久消耗，传送冷却 3 秒。
- 使用原版手杖攻击与移动速度数值。
- 沃尔夫冈手持时可选择缓慢减少或完全停止肌肉值下降。

## 安装

1. 下载仓库并将目录命名为 `ymkit`。
2. 放入《饥荒联机版》的 `mods` 目录，确保 `mods/ymkit/modinfo.lua` 直接存在。
3. 在模组列表中启用“青年的工具”。这是全客户端模组，服务器与所有加入者都需要安装。
4. 更新模组或修改配置后建议完全退出游戏并重新启动。

## ActionQueue RB3

本模组适配 [ActionQueue RB3](https://steamcommunity.com/sharedfiles/filedetails/?id=2873533916)。手持对应工具后，可使用 RB3 的队列快捷键配合左键或右键框选目标。

若旧存档中框选没有触发自定义动作，请先确认双方都使用最新版模组，然后完全重启服务器和客户端。仅在模组页面点击“应用”可能保留旧的内存回调。

## 配置与开发

- 数值和配方集中在 `scripts/util/ymkit_item_stats.lua`。
- 动作及 RB3 适配集中在 `scripts/util/ymkit_actions.lua`。
- 公共注册和工具逻辑集中在 `scripts/util/ymkit_core.lua`。
- 支持 DST `api_version = 10`。
