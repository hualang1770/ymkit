# 青年的工具（ymkit）

《饥荒联机版》工具合集模组。

## 黑曜石战斧

- 用于战斗，拥有 74 点攻击、5 点位面伤害和 1.25 倍手持移速。
- 可范围收割，也可铲掘、采矿、砍树和捕虫。
- 支持隔空铲掘、采矿和砍树。
- 可用于划船，划船效率为 100%。

## 魔法剪刀

- 可造成可配置的真实伤害。
- 可拆解允许反建造的物品并返还材料。
- 可切换为 10 倍效率的锤子形态。
- 支持隔空拆解和隔空锤击。

## 力量魔杖

- 用于传送，使用原版懒人魔杖机制。
- 沃尔夫冈手持时可减缓或停止肌肉值下降。

## 高效肥料

- 一次施肥同时补充三种农田营养。
- 使用次数、每种营养数值和制作材料数量均可配置。

## 万物生长

- 以读书者为中心催熟半径 30 内的适用植物。
- 可处理树木、采摘物、农田作物、蘑菇农场、幼苗和水中木。
- 会照料、浇水并补充农田三种营养，支持巨型作物。
- 可使树精进入睡眠。
