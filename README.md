# 青年的工具（ymkit）

《饥荒联机版》工具合集模组。

## 黑曜石战斧

黑曜石战斧是一把兼顾战斗、采集和航行的多用途工具。手持时提供 1.25 倍移动速度，普通攻击为 74 点伤害，另有 5 点位面伤害；不消耗耐久。

- 默认处于收割形态。右键使用范围收割，可收取角色正前方一片成熟的可采集植物。
- 可切换至挖掘形态，作为铲子使用，挖掘效率为 10；可挖除树桩、作物残株和其他可铲掘目标。
- 具备斧头和鹤嘴锄能力，砍树与采矿效率均为 3 倍，并允许处理强力开采目标。
- 可隔空进行铲掘、砍树和采矿；快速采集与快速捕虫也会替换原版动作，减少连续操作等待。
- 砍倒树木后会自动处理可铲除的树桩，减少切换工具的次数。
- 手持时持续清除角色周围 6 范围内的瘴气。
- 启用划船功能后可作为船桨使用，划船效率为 100%，且划船不会消耗耐久。
- 范围采集、捕虫和隔空工具操作支持 ActionQueue RB3 的左键框选与队列执行。

## 魔法剪刀

魔法剪刀是一把用于战斗、拆解和建筑处理的工具。装备时可造成真实伤害，伤害数值可在模组设置中从 54 调整至 9999；对玩家则保留原版无敌与减伤规则。

- 默认处于拆解形态。右键目标可拆解拥有配方、允许反建造且不受保护的物品，并返还制作材料。
- 可切换为锤子形态，以 10 倍效率锤击建筑、物品和其他可锤击目标。
- 拆解和锤子操作可分别启用隔空执行；启用后无需走近目标即可使用。
- 拆解目标会按照物品当前耐久、保鲜度、燃料等状态计算可返还材料，避免把已消耗部分当作完整物品返还。
- 拆解和隔空锤击支持 ActionQueue RB3 的右键队列操作。

## 力量魔杖

力量魔杖基于原版懒人魔杖的传送机制制作，可无限使用且没有耐久消耗。传送后进入 3 秒充能，充能完成前不能再次传送。

- 使用准星选择落点，按原版传送规则寻找可落脚的位置并播放传送效果。
- 攻击力和手持移动速度沿用原版手杖数值，同时具备暗影等级。
- 沃尔夫冈手持时，默认通过哑铃机制减缓肌肉值下降；可选择完全停止肌肉值下降，卸下魔杖后恢复正常。
- 可使用原版懒人魔杖皮肤。

## 高效肥料

高效肥料用于快速维护农田与普通植物，保留原版肥料的部署、研究、漂浮和熄灭冒烟机制。

- 每次施肥同时补充三种农田营养，不需要分别使用堆肥、粪肥和催长剂。
- 每种营养的补充量可设置为 25、50、75 或 100。
- 可设置每份肥料使用 10、20、50 或 100 次；选择无限使用时，施肥不会消耗物品。
- 会沿用原版粪肥对普通植物的施肥、土壤循环和枯萎恢复效果。

## 万物生长

万物生长是一本范围催熟书，共可使用 5 次。使用“读”后，以读书者为中心处理半径 30 内的适用目标；只有至少成功处理一个目标时才消耗 1 次耐久。

- 可催熟适用的树木、普通植物、草、树枝、浆果丛、芦苇等采摘物。
- 可处理耕地作物的生长阶段；会自动照料、浇水，并补充三种营养各 100 点，同时支持巨型作物。
- 可催熟蘑菇、蘑菇农场、树木幼苗和石果幼苗。
- 可加速水中木种子与水中木的成长冷却。
- 会让范围内的树精进入长时间睡眠。
- 兼容万物书的三种特殊树桩。
- 周围没有可处理的目标时会提示“没有可催熟的植物”，不会消耗使用次数。
